# task-cli

Command-line task manager built with TypeScript and Node.js, featuring JSON-based persistence and a clean, typed codebase.

## Description

`task-cli` is a command-line tool for managing everyday tasks. Tasks are saved to a local JSON file (`tasks.json`), letting you add, list, complete, and remove tasks quickly and simply, with no external database required.

## Installation

Prerequisites: [Node.js](https://nodejs.org/) 18+ and npm.

```bash
# Install dependencies
npm install

# Build the TypeScript project
npm run build
```

After building, the CLI can be run with:

```bash
node dist/index.js <command>
```

Or, during development, without compiling first:

```bash
npm run dev -- <command>
```

## Available commands

| Command | Description |
|---|---|
| `add "task title"` | Adds a new task |
| `list` | Lists all tasks |
| `done <id>` | Marks a task as completed |
| `remove <id>` | Removes a task |
| `help` | Shows help with available commands |

### Usage examples

```bash
# Add a new task
node dist/index.js add "Buy milk"
# Tarefa adicionada: [ ] #1 Buy milk

# List all tasks
node dist/index.js list
# [ ] #1 Buy milk

# Mark task #1 as completed
node dist/index.js done 1
# Tarefa concluida: [x] #1 Buy milk

# Remove task #1
node dist/index.js remove 1
# Tarefa removida: [x] #1 Buy milk

# Show help
node dist/index.js help
```

Tasks are persisted to the `tasks.json` file, automatically created in the directory where the command is run.

## Project structure

```
task-cli/
├── src/
│   ├── cli/
│   │   └── commands.ts     # CLI command logic (add, list, done, remove, help)
│   ├── data/
│   │   ├── task.ts         # Task entity types/interfaces
│   │   └── taskStore.ts    # Persistence layer (JSON read/write)
│   └── index.ts            # CLI entry point (argument parsing)
├── dist/                   # Compiled output (generated by build)
├── tasks.json              # Local data file (generated at runtime)
├── package.json
├── tsconfig.json
└── .gitignore
```

## Technologies used

- [TypeScript](https://www.typescriptlang.org/) — static typing and safer code
- [Node.js](https://nodejs.org/) — runtime environment
- [ts-node](https://typestrong.org/ts-node/) — direct TypeScript execution in development
- JSON file-based persistence, with no external database dependencies
